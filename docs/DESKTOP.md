# DSH 桌面版支持

**液态玻璃皮肤插件从 v1.4.2 起已支持 DSH 桌面版。** 当前确认的环境是 Windows DSH `0.2.0-rc.2`；其他桌面版本与非 Windows 平台尚未实测。

## 安装

先打开一次 DSH 桌面版以初始化 `desktop` profile，再正常退出应用。下载本仓库的安装脚本并执行：

```powershell
Invoke-WebRequest 'https://raw.githubusercontent.com/SuperSgdk/DSH-Liquid-Glass-Theme/main/install.ps1' -OutFile install-liquid-glass.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-liquid-glass.ps1 -Version v1.4.2 -Profile desktop
```

省略 `-Version` 会安装最新 GitHub Release。安装目录优先使用显式传入的 `-DshHome`；未传入时读取 `DSH_HOME` 环境变量，该变量为空时才使用用户目录下的 `.dsh`。

安装器只处理指定 profile 的插件注册和链接，先备份配置与原链接信息。安装后重新打开桌面版，在 **设置 → 通用设置** 的外观附近找到主题开关；模糊、磨砂、背景及壁纸控件仍在外观下方。关闭主题可恢复原生界面。

## 本次适配

- 桌面版移除了旧勾选图标导出及 `settings.plugin.item` 插槽。插件使用本地 SVG 图标，并在 Windows 桌面版的通用设置中提供主题开关。
- Windows 主对话列新增不透明底板。启用主题时仅清除该背景，保留布局和原生圆角。
- 左侧栏收起时，玻璃滤镜、悬停变换与裁剪会隐藏标题栏中的固定展开按钮。仅在收起状态清除这些效果，让按钮继续可用。
- 原皮肤的宽泛 panel 选择器同时装饰右栏外壳和内层。右栏关闭后仍挂载，残留边框会穿过对话区；本次清除关闭外壳及内层边框，打开时保留一个外层玻璃边缘。
- 输入底栏按可用宽度横排、自动换行，与 `dsh-cost-meter` 计费按钮和摘要共同显示；编辑区仍按草稿内容增高，费用计算与数据不变。
- 统计栏使用官方 `data-composer-stats` 标记，不再给其他插件的 root 元素误加统计栏样式。

## 验证状态

2026-10-01 在真实 Windows 桌面版加载并应用修复，用户确认当前显示和操作已无上述问题。

后台隔离检查使用安装应用的实际布局样式、右栏组件结构、插件构建 CSS 与真实统计标记逻辑：

| 检查 | 结果 |
| --- | --- |
| 主对话背景：新/已有会话、深浅色、浮动/兼容、样式加载顺序 | 16 种组合通过 |
| 右栏：展开/收起、深浅色、样式加载顺序、开关主题 | 16 种组合通过 |
| 左栏收起及悬停变换残留 | 展开/新会话按钮可命中，展开布局保持 |
| 输入区：宽窄窗口、多行草稿、无计费/无统计、新会话、深浅色、关闭主题 | 17 个关键用例通过 |

隔离输入区的总高在 1050 CSS px 视口为 200→133px，700 宽为 200→157px，400 宽为 200→177px。编辑卡片本体高度保留，费用摘要完整换行，无横向溢出；这些数字来自隔离布局检查，不代表所有系统缩放下的屏幕像素。

Web 与桌面版的 localStorage/IndexedDB 各自独立，壁纸与视觉偏好不会自动跨端同步。桌面端视频文件授权及其他版本的行为仍需按环境验证。
